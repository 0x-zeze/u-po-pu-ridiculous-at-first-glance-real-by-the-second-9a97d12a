One-sentence bizarre-but-bankable startup pitch for make.fun's **Ridiculous at First Glance, Real by the Second** bounty. The program writes a single pitch sentence (max 200 characters) to `/output/entry.txt`.

## The pitch

> We auction the naming rights to city potholes, so jilted lovers pay to name a crater after their ex — and the city uses the cash to finally fill it.

148 characters. Ridiculous at first glance (naming a pothole after your ex), real by the second (jilted lovers pay, the city funds the repair — a petty-revenge marketplace that paves roads).

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22. Deterministic: the pitch is a constant string — no randomness, no time, no network. Two runs produce byte-identical output.
